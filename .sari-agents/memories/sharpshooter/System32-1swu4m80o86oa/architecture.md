## Model Orchestration

- Distribute workloads across multiple specialized AI models, tools, or agents rather than routing all tasks to a single model.
- Use fast models exclusively and replace retired AI models.
- Bulbhul agents templates match the MCP bulbhul agents specification and are managed via clasp.

## Boundaries

- Preserve existing authentication, frontend, Apps Script backend, routes, and Mallik layer boundaries without unauthorized bypasses or unnecessary rebuilds.
