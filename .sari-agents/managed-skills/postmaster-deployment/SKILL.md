# Postmaster Deployment & Hosting Intelligence

Guide for deploying Postmaster and full-stack applications for $0 using top-tier free cloud platforms.

## Supported Deployment Pathways

### 1. Static SPA Tier (Vercel, Netlify, Cloudflare Pages, GitHub Pages)
- **Config Files Added**: `vercel.json`, `netlify.toml`.
- **Cost**: $0 / unlimited bandwidth.
- **Features**: Global CDN, automated SSL, instant git push deployment.

### 2. Full-Stack Container Tier (Render, Railway, Fly.io)
- **Use Case**: Hosting the Docker microservice backend (`docker-compose.yml`, Node API, Postgres, Redis).
- **Cost**: Free tier / low usage credit.

### 3. Database Tier (Supabase, Neon)
- **Use Case**: Cloud PostgreSQL persistence.
