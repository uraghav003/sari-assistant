## Product Scope
- General AI-based operational system powered by the central dynamic mind "bulbhul", with unrelated domains like loan automation removed or shifted to storage to prevent repository confusion.
- Core product purpose: continuously monitor all repositories and Model Context Protocol (MCP) instances associated with the account for errors and instantly resolve them upon detection, collaborating with or reporting to Sari while keeping non-monitoring work minimal or zero.
- AI model errors must be resolved immediately before proceeding with any other tasks or actions (subtle).
- The Bulbhul AI Personal Banker system operates exclusively for internal staff rather than public-facing clients.
- Scope constraint: restrict work to upgrading, fixing, or refining existing functionality without introducing new features; execute live testing using dummy entries across three banks with corresponding updates for managers, MD, founder, and workspace details (subtle).
- Active subagents run to fix tasks in fasting mode (subtle).
