# Cloudflare Wrangler & Workers Operations
Use for deploying Cloudflare Workers, Pages, and managing Cloudflare MCP services via Wrangler CLI.

## Key Commands
- `npx wrangler dev`: Run local worker development server.
- `npx wrangler deploy`: Deploy worker to Cloudflare edge.
- `npx wrangler mcp`: Start Cloudflare Model Context Protocol server.
- `npx wrangler secret put <NAME>`: Securely store environment secrets.
